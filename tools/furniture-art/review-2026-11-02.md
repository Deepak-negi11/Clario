## Security fixes

- **Public admin signup:** public requests cannot select administrator privileges. A forged
  `role` field cannot override the normal user role. Admin fixtures now use trusted database
  provisioning. Existing account roles were retained; operators should review existing admins
  because the earlier signup endpoint allowed this escalation.
- **Authentication:** every production startup path requires a non-placeholder JWT secret of
  at least 32 characters. Verification explicitly accepts HS256. Signup/signin are throttled
  per peer IP with `Retry-After`. Forwarded IPs require explicit `TRUST_PROXY=true`.
- **Sockets:** browser-origin checks, size/frequency caps, protection against simultaneous joins,
  disconnect cleanup during pending joins, and silencing replaced tabs for chat/reactions.
- **HTTP:** production CORS uses the configured allowlist; bodies are capped, unexpected errors
  return generic responses, and frontend/API framing, content-type and referrer headers are set.
- **GitHub privacy:** only explicitly public repositories can supply context to a visitor or
  external AI. A broad operator token cannot expose private metadata or files. Redirects fail.
- **Dependencies:** Next.js 16.4.4, Axios 1.21.0, Nodemailer 10.1.4, Zod 4.6.7 and compatible
  transitive updates. Unused NextAuth was removed. Prisma client generation was rerun after
  the compatible Prisma update; no database schema migration was needed.

The dependency scan decreased from 117 advisory entries (7 critical, 57 high, 45 moderate,
8 low) to **one moderate**, with no remaining high or critical findings. The remaining
[minimatch glob amplification advisory](https://github.com/advisories/GHSA-g3hv-75wg-m249)
is in the ESLint/TypeScript lint dependency tree. Its patched major version changes APIs
expected by older consumers; a global override would break linting. The advisory is recorded,
not suppressed. The application does not accept user-controlled glob patterns.

This source/dependency/local functional review does not certify a deployment. Deployment still
needs HTTPS, restricted Postgres/Redis access and correctly configured origins/proxy trust.
AI quotas remain in memory per frontend process; the public mentor/coworker endpoints need
shared quota controls when deployed across multiple instances.
